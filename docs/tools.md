## Uploads (special-cased)

| Tool | Method | Endpoint | Params | Write | Admin |
| --- | --- | --- | --- | --- | --- |
| `alist_fs_put` | PUT | `/api/fs/put` | localPath*, path*, asTask | yes | no |
| `alist_fs_form` | PUT | `/api/fs/form` | localPath*, path*, asTask | yes | no |

- `alist_fs_put` — Stream a local file (Host-side absolute path) to AList. Respects maxUploadBytes. Honours As-Task.
- `alist_fs_form` — Upload a local file as multipart/form-data, for drivers that require a form upload.
